## 1. Event Types

### Event (google.adk.events.Event)

The fundamental unit of communication in ADK.

**Source:** `google/adk/events/event.py`

```python
from google.adk.events import Event, EventActions
from google.genai import types

class Event(LlmResponse):
    """Represents an event in a conversation between agents and users."""
    
    # === Identity & Timing ===
    
    id: str = ''
    """Unique identifier for this event (ULID format).
    Auto-generated by SessionService if empty."""
    
    invocation_id: str = ''
    """ID for the entire user-request-to-final-response cycle.
    Groups all events in one conversational turn."""
    
    author: str
    """Event author: 'user', agent name (e.g., 'MyAgent'), or tool name.
    Required field."""
    
    timestamp: float = Field(default_factory=lambda: datetime.now().timestamp())
    """Unix timestamp with milliseconds. Auto-generated."""
    
    branch: Optional[str] = None
    """Agent hierarchy path (e.g., 'agent1.agent2.agent3').
    Used for multi-agent isolation."""
    
    # === Content (inherited from LlmResponse) ===
    
    content: Optional[types.Content] = None
    """The actual message content. See Content types below."""
    
    partial: Optional[bool] = None
    """True if this is a streaming chunk. False or None for complete."""
    
    error_code: Optional[str] = None
    """Error code if event represents an error:
    - 'SAFETY': Content blocked by safety filters
    - 'RECITATION': Plagiarism detected
    - 'QUOTA_EXCEEDED': API quota hit
    - 'DEADLINE_EXCEEDED': Timeout
    - 'OTHER': General error
    """
    
    error_message: Optional[str] = None
    """Human-readable error description."""
    
    usage_metadata: Optional[dict] = None
    """Token usage information:
    {
        "prompt_tokens": int,
        "completion_tokens": int,
        "total_tokens": int
    }
    """
    
    # === Actions ===
    
    actions: EventActions = Field(default_factory=EventActions)
    """Side effects and control signals. See EventActions below."""
    
    long_running_tool_ids: Optional[set[str]] = None
    """Set of function call IDs for async/long-running tools."""
    
    # === Computed Fields ===
    
    turn_complete: Optional[bool] = None
    """Whether this turn is complete (set by framework)."""
    
    # === Methods ===
    
    def get_function_calls(self) -> list[FunctionCall]:
        """Extract all function calls from content.parts."""
        
    def get_function_responses(self) -> list[FunctionResponse]:
        """Extract all function responses from content.parts."""
        
    def has_trailing_code_execution_result(self) -> bool:
        """Check if last part is code execution result."""
        
    def is_final_response(self) -> bool:
        """Returns True if this event should be displayed to user.
        
        True when:
        - Has function response with skip_summarization=True
        - Has long_running_tool_ids
        - Has text content (no function calls/responses, not partial)
        """
    
    @staticmethod
    def new_id() -> str:
        """Generate new ULID for event ID."""
```

**Example Usage:**

```python
from google.adk.events import Event, EventActions
from google.genai import types

# User message event
user_event = Event(
    author="user",
    invocation_id="inv_123",
    content=types.Content(
        role="user",
        parts=[types.Part(text="Hello!")]
    )
)

# Agent response event
agent_event = Event(
    author="MyAgent",
    invocation_id="inv_123",
    content=types.Content(
        role="model",
        parts=[types.Part(text="Hi there!")]
    ),
    actions=EventActions(
        state_delta={"greeting_count": 1}
    )
)

# Function call event
func_call_event = Event(
    author="MyAgent",
    invocation_id="inv_123",
    content=types.Content(
        role="model",
        parts=[types.Part(
            function_call=types.FunctionCall(
                name="get_weather",
                id="call_123",
                args={"city": "Paris"}
            )
        )]
    )
)
```

### EventActions (google.adk.events.EventActions)

**Source:** `google/adk/events/event_actions.py`

```python
class EventActions:
    """Actions and side effects attached to an event."""
    
    state_delta: dict[str, Any] = Field(default_factory=dict)
    """State changes to merge into session.state.
    
    Example:
        {"score": 100, "level": 2}
    
    Merging (shallow):
        current_state = {"score": 50, "name": "Alice"}
        state_delta = {"score": 100, "level": 2}
        new_state = {"score": 100, "level": 2, "name": "Alice"}
    """
    
    artifact_delta: dict[str, types.Part] = Field(default_factory=dict)
    """Artifacts saved during this event.
    
    Key: filename
    Value: Part object with artifact data
    
    Example:
        {
            "chart.png": Part(inline_data=Blob(...)),
            "data.csv": Part(inline_data=Blob(...))
        }
    """
    
    transfer_to_agent: Optional[str] = None
    """Transfer control to another agent by name.
    
    Example:
        "WeatherAgent"  # Transfer to WeatherAgent
    """
    
    escalate: Optional[bool] = None
    """Signal to exit a LoopAgent.
    
    When True, the current loop terminates.
    """
    
    skip_summarization: Optional[bool] = None
    """Skip LLM summarization of tool result.
    
    When True, the function_response is treated as final and
    displayed directly to the user without LLM processing.
    """
    
    requested_auth_configs: list[AuthConfig] = Field(default_factory=list)
    """Authentication configs requested by tools.
    
    Used for OAuth flows and API key requests.
    """
    
    requested_tool_confirmations: list[ToolConfirmation] = Field(default_factory=list)
    """Tool confirmations requested for HITL (Human-in-the-Loop).
    
    Pauses execution for user confirmation before tool execution.
    """
    
    agent_state: Optional[BaseAgentState] = None
    """Agent-specific state for resumable agents (internal use)."""
    
    end_of_agent: Optional[bool] = None
    """Marks end of agent execution (internal use)."""
```

## 2. Session Types

### Session (google.adk.sessions.Session)

**Source:** `google/adk/sessions/session.py`

```python
from google.adk.sessions import Session
from google.adk.events import Event

class Session:
    """A conversation session with complete history and state."""
    
    id: str
    """Unique session identifier (ULID format)."""
    
    app_name: str
    """Application name this session belongs to."""
    
    user_id: str
    """User identifier this session belongs to."""
    
    events: list[Event]
    """Complete chronological event history.
    
    All events from session creation to present.
    """
    
    state: dict[str, Any]
    """Session state dictionary.
    
    Arbitrary JSON-serializable data. Updated by merging
    state_delta from events.
    
    Example:
        {
            "user_name": "Alice",
            "score": 100,
            "preferences": {
                "theme": "dark",
                "language": "en"
            }
        }
    """
    
    create_time: datetime
    """When session was created (UTC)."""
    
    last_update_time: datetime
    """When session was last updated (UTC)."""
    
    custom_metadata: Optional[dict[str, Any]] = None
    """Optional custom metadata (application-specific)."""
```

**Session Lifecycle:**

```python
# Create
session = await session_service.create_session(
    app_name="my_app",
    user_id="user_123",
    session_id="session_abc",  # Optional
    state={"initial": "state"}   # Optional
)

# Use
session.events.append(new_event)
session.state.update({"new_key": "value"})

# Persist
await session_service.append_event(
    app_name="my_app",
    user_id="user_123",
    session_id="session_abc",
    event=new_event
)

# Retrieve
session = await session_service.get_session(
    app_name="my_app",
    user_id="user_123",
    session_id="session_abc"
)

# Delete
await session_service.delete_session(
    app_name="my_app",
    user_id="user_123",
    session_id="session_abc"
)
```

## 4. Service Interfaces

### BaseSessionService

**Source:** `google/adk/sessions/base_session_service.py`

```python
from abc import ABC, abstractmethod
from google.adk.sessions import Session
from google.adk.events import Event

class BaseSessionService(ABC):
    """Abstract interface for session persistence."""
    
    @abstractmethod
    async def create_session(
        self,
        app_name: str,
        user_id: str,
        session_id: Optional[str] = None,
        state: Optional[dict[str, Any]] = None,
    ) -> Session:
        """Create a new session.
        
        Args:
            app_name: Application identifier
            user_id: User identifier
            session_id: Optional session ID (generated if None)
            state: Optional initial state
            
        Returns:
            Created Session object
        """
    
    @abstractmethod
    async def get_session(
        self,
        app_name: str,
        user_id: str,
        session_id: str,
    ) -> Session:
        """Retrieve an existing session.
        
        Args:
            app_name: Application identifier
            user_id: User identifier
            session_id: Session identifier
            
        Returns:
            Session object with full event history
            
        Raises:
            SessionNotFoundError: If session doesn't exist
        """
    
    @abstractmethod
    async def list_sessions(
        self,
        app_name: str,
        user_id: str,
        limit: int = 20,
        offset: int = 0,
    ) -> list[Session]:
        """List sessions for a user.
        
        Args:
            app_name: Application identifier
            user_id: User identifier
            limit: Maximum sessions to return
            offset: Pagination offset
            
        Returns:
            List of Session objects (may have empty events list)
        """
    
    @abstractmethod
    async def append_event(
        self,
        app_name: str,
        user_id: str,
        session_id: str,
        event: Event,
    ) -> Event:
        """Append event to session and apply side effects.
        
        This method:
        1. Assigns event.id if not set
        2. Applies event.actions.state_delta to session.state
        3. Records event.actions.artifact_delta metadata
        4. Appends event to session.events
        5. Updates session.last_update_time
        6. Persists changes
        
        Args:
            app_name: Application identifier
            user_id: User identifier
            session_id: Session identifier
            event: Event to append
            
        Returns:
            Event with id and timestamp populated
        """
    
    @abstractmethod
    async def update_state(
        self,
        app_name: str,
        user_id: str,
        session_id: str,
        state_delta: dict[str, Any],
    ) -> Session:
        """Update session state (merge operation).
        
        Args:
            app_name: Application identifier
            user_id: User identifier
            session_id: Session identifier
            state_delta: Changes to merge into state
            
        Returns:
            Updated Session object
        """
    
    @abstractmethod
    async def delete_session(
        self,
        app_name: str,
        user_id: str,
        session_id: str,
    ) -> None:
        """Delete a session and all its data.
        
        Args:
            app_name: Application identifier
            user_id: User identifier
            session_id: Session identifier
        """
```

from abc import ABC, abstractmethod

class BaseArtifactService(ABC):
    """Abstract interface for artifact storage."""
    
    @abstractmethod
    async def save_artifact(
        self,
        app_name: str,
        user_id: str,
        session_id: str,
        filename: str,
        content: bytes,
        mime_type: str,
    ) -> str:
        """Save an artifact.
        
        Args:
            app_name: Application identifier
            user_id: User identifier
            session_id: Session identifier
            filename: Artifact filename
            content: Binary content
            mime_type: MIME type
            
        Returns:
            Artifact identifier/path
        """
    
    @abstractmethod
    async def load_artifact(
        self,
        app_name: str,
        user_id: str,
        session_id: str,
        filename: str,
    ) -> tuple[bytes, dict[str, Any]]:
        """Load an artifact.
        
        Args:
            app_name: Application identifier
            user_id: User identifier
            session_id: Session identifier
            filename: Artifact filename
            
        Returns:
            Tuple of (content, metadata)
            metadata contains: mime_type, size, create_time, etc.
        """
    
    @abstractmethod
    async def list_artifacts(
        self,
        app_name: str,
        user_id: str,
        session_id: str,
    ) -> list[dict[str, Any]]:
        """List all artifacts for a session.
        
        Args:
            app_name: Application identifier
            user_id: User identifier
            session_id: Session identifier
            
        Returns:
            List of artifact metadata dictionaries
        """
    
    @abstractmethod
    async def delete_artifact(
        self,
        app_name: str,
        user_id: str,
        session_id: str,
        filename: str,
    ) -> None:
        """Delete an artifact.
        
        Args:
            app_name: Application identifier
            user_id: User identifier
            session_id: Session identifier
            filename: Artifact filename
        """

### ToolContext

**Source:** `google/adk/tools/tool_context.py`

```python
from google.adk.tools import ToolContext

class ToolContext:
    """Context provided to tool functions.
    
    Tools can accept this as their last parameter.
    """
    
    invocation_context: InvocationContext
    """Parent invocation context."""
    
    function_call_id: str
    """ID of the function call being executed."""
    
    event_actions: EventActions
    """Actions to attach to the result event.
    
    Tools can modify:
    - event_actions.state_delta (update session state)
    - event_actions.skip_summarization (skip LLM processing)
    - event_actions.transfer_to_agent (transfer control)
    """
    
    # Convenience accessors
    
    @property
    def state(self) -> dict[str, Any]:
        """Access session state (read/write)."""
        return self.invocation_context.state
    
    async def save_artifact(
        self,
        filename: str,
        content: bytes,
        mime_type: str,
    ) -> None:
        """Save an artifact and update artifact_delta.
        
        Automatically adds to event_actions.artifact_delta.
        """
```

**Tool Usage:**

```python
from google.adk.tools import ToolContext

def my_tool(arg1: str, arg2: int, tool_context: ToolContext) -> dict:
    """My custom tool.
    
    Args:
        arg1: First argument
        arg2: Second argument
        tool_context: Automatically provided by ADK
        
    Returns:
        Tool result
    """
    # Access session state
    user_name = tool_context.state.get("user_name", "User")
    
    # Update state
    tool_context.event_actions.state_delta["tool_calls"] = \
        tool_context.state.get("tool_calls", 0) + 1
    
    # Do work
    result = perform_operation(arg1, arg2)
    
    # Save artifact if needed
    if result.has_chart:
        await tool_context.save_artifact(
            filename="chart.png",
            content=result.chart_bytes,
            mime_type="image/png"
        )
    
    return {"status": "success", "result": result}
```

## 6. State Management

### State Structure

Session state is a flat dictionary with arbitrary keys:

```python
{
    # User preferences
    "theme": "dark",
    "language": "en",
    
    # Conversation context
    "user_name": "Alice",
    "current_topic": "weather",
    
    # Agent outputs (via output_key)
    "extracted_info": {...},
    "analysis_result": {...},
    
    # Custom application data
    "score": 100,
    "level": 2,
    "achievements": ["first_chat", "power_user"],
    
    # Nested data
    "user_profile": {
        "name": "Alice",
        "age": 30,
        "preferences": {...}
    }
}
```

### State Delta Merging

State updates use **shallow merge**:

```python
current_state = {
    "a": 1,
    "b": 2,
    "c": {"d": 3}
}

state_delta = {
    "b": 999,           # Update existing
    "e": 4,             # Add new
    "c": {"f": 5}       # Replace nested (not deep merge!)
}

# Result
new_state = {
    "a": 1,             # Unchanged
    "b": 999,           # Updated
    "e": 4,             # Added
    "c": {"f": 5}       # Replaced (d is lost!)
}
```

### Temporary State

Keys prefixed with `"temp:"` are not persisted:

```python
state_delta = {
    "temp:working_data": "...",    # Lost after invocation
    "final_result": "..."           # Persisted
}
```

### State Scopes

Keys can use prefixes to indicate scope:

```python
{
    # App-level (across all users)
    "app:global_setting": "value",
    
    # User-level (across all sessions for this user)
    "user:preference": "value",
    
    # Session-level (default, no prefix needed)
    "session_data": "value",
    
    # Temporary (not persisted)
    "temp:calculation": "value"
}
```

> **Note:** Scope handling depends on SessionService implementation.
